# Housing Price Prediction

## Project Overview
This project implements a complete Machine Learning lifecycle to predict house prices using Linear Regression.

## Problem Statement
The goal is to predict the selling price of a house based on features such as:
- Square Feet
- Bedrooms
- Bathrooms
- Age
- Location

## Dataset
The project uses the Housing Dataset provided during the internship.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib

## Machine Learning Workflow
1. Load Dataset
2. Data Exploration
3. Handle Missing Values
4. One-Hot Encoding
5. Train/Test Split
6. Linear Regression Model
7. Model Evaluation
8. Save Model
9. Predict House Price

## Evaluation Metrics

- RMSE: 33,622.17
- R² Score: 0.9590
